# Mindfulness Guide

正念引导工具，提供呼吸练习、身体扫描、压力缓解等功能。

## 功能特点

- 🧘 呼吸练习 - 4-7-8、方块呼吸、深度呼吸
- 🔍 身体扫描 - 全身放松冥想
- 💆 压力缓解 - 根据压力等级给出建议
- 🌙 睡前放松 - 帮助入睡的引导

## 快速开始

```bash
cd ~/.openclaw/skills/mindfulness-guide
python3 scripts/main.py breathe
python3 scripts/main.py body-scan
python3 scripts/main.py demo
```
